# 短信推送助手 / SmsForwarder Assistant · Bark-Android v1.3

[中文使用说明](https://github.com/1Fann/SmsForwarder-assistant/blob/main/README.md) · [English guide](https://github.com/1Fann/SmsForwarder-assistant/blob/main/README.en.md)

## 中文

**安卓 Bark 服务端与短信推送助手。** 本次为源码发布，不附带 APK 安装包。下方自动生成的 Source code ZIP / tar.gz 是源码，不能直接安装到手机。

### 两种用途

- **独立安卓 Bark 服务端**：在 ARM64 安卓手机上启动 Bark、查看配对地址、绑定 iPhone 并发送测试提醒。只需要自建 Bark 服务的人也能使用，无需安装或启用短信转发器。
- **安卓短信推送到 iPhone**：配合官方 SmsForwarder，配置本机发送通道、全部 SIM 短信规则、权限修复和失败重试。

### v1.3 功能

- Android 适配的 Bark 服务端 2.3.9，后台前台服务运行，支持手动启动与停止。
- 辅助安装官方 SmsForwarder 3.5.0 ARM64，并进行一键配置。
- 修复短信接收、小米通知类短信、自启动和后台运行权限。
- 独立 Root 定时守护同时检测 Bark 和短信转发器；完整检查间隔可设置为 1–1440 分钟，默认 5 分钟，并约每 10 秒检查服务退出情况。
- 异常恢复尊重手动关闭状态；包含失败重试配置和短信气泡、铃铛图标。

### 使用与构建

- Android 8.0+、ARM64、iPhone Bark。短信自动配置、权限修复与独立定时守护需要 Root。
- 单独启动 Bark 的代码不调用 Root，但非 Root 设备尚未实机验证；已验证环境为 Android 13 / Redmi / Magisk。
- 首次配对使用同一 Wi-Fi；配对后 iPhone 通过 Apple APNs 收通知，日常接收不要求与安卓在同一 Wi-Fi。访问 Bark 接口的调用方仍须能连接安卓服务。
- 源码构建时，准备脚本从官方获取依赖并校验固定 SHA-256；获取的推送组件及官方短信转发器会打包进本地生成的 APK。
- 构建步骤、两种用途的操作流程和运行说明见[项目首页](https://github.com/1Fann/SmsForwarder-assistant#readme)。本次 Release 不执行 APK 构建或上传。

### 验证范围

本地构建与配置测试通过。实机已验证短信推送、两个服务被强制结束后的恢复、小米通知类短信权限恢复及手动停止保护；尚未完成整机重启和另一台全新手机的完整安装验证。

助手采用 MIT 许可证，Bark 与 SmsForwarder 保留各自的上游许可证。本项目是独立社区项目，非两者官方客户端。

## English

**A Bark server for Android, with optional SMS forwarding to iPhone.** This is a source-only release with no APK attached. The automatically generated Source code ZIP / tar.gz archives contain source code and cannot be installed directly on a phone.

### Two use cases

- **Standalone Bark server on Android**: start Bark on an ARM64 Android phone, view registration addresses, register an iPhone, and send test notifications. You can use it solely to host Bark without installing or enabling SmsForwarder.
- **Android SMS notifications on iPhone**: use the official SmsForwarder app to configure a local sender channel, SMS rules for all SIMs, permission repairs, and retries.

### v1.3 features

- Bark server 2.3.9 adapted for Android, running through an Android foreground service with manual start and stop controls.
- Assisted installation and one-click configuration of the official SmsForwarder 3.5.0 ARM64 app.
- Repairs for SMS reception, Xiaomi notification-SMS access, autostart, and background execution permissions.
- An independent root monitor checks both Bark and SmsForwarder. Full checks run every 1–1440 minutes, defaulting to 5 minutes; lightweight checks detect service exits approximately every 10 seconds.
- Recovery respects manual-off settings. Includes failed-delivery retry configuration and an adaptive speech-bubble and bell icon.

### Usage and building

- Requires Android 8.0+, ARM64, and Bark on iPhone. Automatic SMS configuration, permission repairs, and independent scheduled monitoring require root.
- Standalone Bark startup does not invoke root, but unrooted devices have not been tested on hardware. The verified environment is Android 13 / Redmi / Magisk.
- Initial registration uses the same Wi-Fi. The iPhone subsequently receives notifications through Apple APNs and does not need to remain on the same Wi-Fi. Applications calling the Bark endpoint must still be able to reach the Android server.
- At build time, the preparation script obtains official upstream dependencies and verifies pinned SHA-256 hashes. The push component and official SmsForwarder installer are bundled into the locally built APK.
- See the [English guide](https://github.com/1Fann/SmsForwarder-assistant/blob/main/README.en.md) for build steps, both setup flows, and operation details. This release does not build or upload an APK. The app's current interface is Chinese; the English guide translates the relevant controls.

### Validation and licensing

Local builds and configuration tests passed. Hardware checks verified SMS delivery, recovery after force-stopping either service, restoration of Xiaomi notification-SMS permission, and manual-stop protection. Full reboot validation and a complete first install on a second, fresh phone remain untested.

The assistant uses the MIT license. Bark and SmsForwarder retain their upstream licenses. This is an independent community project, not an official client of either upstream project.
